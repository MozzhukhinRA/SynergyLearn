# Учебная практика — кейс-задачи 1–5

Репозиторий содержит выполнение индивидуального задания по технологической
(проектно-технологической) практике.

Структура проекта:

- `case_01_birthdate` — программа для работы с датой рождения;
- `case_02_counter` — простой счётчик на HTML/CSS/JavaScript;
- `case_03_django_greeting` — веб-приложение Django с сохранением имени в БД;
- `case_04_calculator` — интерактивный калькулятор;
- `case_05_analysis` — аналитический обзор кейса №3.

Каждый кейс находится в отдельной папке и содержит собственный `README.md`
с инструкцией по запуску.

## Используемые технологии

- Python 3
- HTML5
- CSS3
- JavaScript
- Django
- SQLite

## Автор

Студент направления «Математическое обеспечение и администрирование
информационных систем», профиль «Разработка программного обеспечения
(Full-stack разработка)».
